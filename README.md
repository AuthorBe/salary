# SalaryApp - Aplikasi Payroll Karyawan Multi-Tipe

## Tentang Proyek
SalaryApp adalah aplikasi berbasis web yang dirancang khusus untuk manajemen dan penghitungan payroll (gaji) karyawan. 

Aplikasi ini dikembangkan untuk menangani alur bisnis penggajian yang kompleks, sehingga proses perhitungan yang sebelumnya memakan waktu atau rawan kesalahan dapat diotomatisasi secara akurat.

## Fungsi Utama
Aplikasi ini memiliki fitur dan fungsi utama sebagai berikut:
- **Dukungan Multi-Tipe Karyawan:** Mampu menghitung gaji untuk 2 tipe karyawan (Borongan dan Bulanan) sesuai dengan kebijakan perusahaan.
- **Sistem Borongan Kelompok:** Memiliki logika untuk menghitung dan membagikan harga borongan yang dikerjakan secara berkelompok.
- **Uang Bulanan:** Menangani komponen uang bulanan yang berlaku lintas-tipe karyawan.
- **Manajemen Hutang Fleksibel:** Mendukung pencatatan dan pemotongan hutang karyawan secara dinamis pada saat periode penggajian.

## Status Aplikasi
⚠️ **PERHATIAN: Aplikasi ini berstatus INTERNAL.** 
Sistem ini dibuat eksklusif untuk kebutuhan operasional internal perusahaan dan tidak ditujukan untuk penggunaan publik.
